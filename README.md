# st-guitar-fingering-training

Training and evaluation lab for guitar polyphony, voicing, string/fret selection, and left-hand fingering models.

## Current scope

The first learned task is **observed string/fret placement ranking among physically valid candidates**. Deterministic guitar physics remains authoritative; learned models never create or legitimize physically impossible placements.

The repository intentionally excludes OMR/PDF recognition, production GuitarTab Engine writes, automatic learning from user feedback, copyrighted/rights-unclear corpora, and large checkpoints.

See `ARCHITECTURE.md`, `SAFETY.md`, `DATASET_CONTRACT.md`, `ROADMAP.md`, and `STATUS.md`.
