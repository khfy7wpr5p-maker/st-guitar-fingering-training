# S2-A.v3 FINAL boundary

The FINAL export supplied by the Teacher is intentionally not used during v3 protocol/model selection.

Required execution order:

1. validate DEVELOPMENT export and manifest identity;
2. compute repeat consensus and quarantine every disagreeing semantic task;
3. run all frozen v3 DEVELOPMENT CV gates;
4. verify 10/10 deterministic CV signatures;
5. fit all stable DEVELOPMENT originals;
6. compute and seal the v3 model digest/artifact;
7. only then invoke the FINAL loader;
8. evaluate the untouched FINAL once against the already-frozen thresholds.

Any exception or failed DEVELOPMENT check before step 6 means the FINAL loader must not be called.
